# Dashboard de Vendas em Power BI

## Sobre o projeto

Este projeto foi desenvolvido durante minha participação em uma formação em Engenharia e Análise de Dados promovida pela **MCIO Brasil em parceria com a Leega Academy**.

A formação faz parte da minha jornada de desenvolvimento profissional na área de dados. No **Módulo 3**, dedicado a Engenharia e Arquitetura de Dados, uma das etapas práticas apresentou conceitos de modelagem e visualização de dados utilizando o **Microsoft Power BI**.

A partir da base de treinamento e dos exercícios apresentados nas aulas, reproduzi as transformações propostas e, em seguida, ampliei o projeto por iniciativa própria.

Além das atividades realizadas durante o treinamento, desenvolvi:

- um dashboard de visão geral das vendas;
- indicadores de receita, lucro, quantidade vendida e margem;
- filtros por ano, trimestre, produto, estado e canal de vendas;
- uma dimensão calendário para análise temporal;
- medidas adicionais utilizando DAX;
- uma análise de Receita Realizada x Receita Estimada;
- indicadores de diferença e percentual de atingimento das metas;
- análise dos resultados por produto;
- uma página de resumo executivo com interpretação dos resultados e recomendações de negócio.

O objetivo dessa ampliação foi transformar um exercício de aprendizagem em um pequeno projeto de análise de dados, passando pelas etapas de transformação, modelagem, criação de métricas, visualização e interpretação dos resultados.
